# PWA 数据指挥舱主轴强化 Design

## Goal
把 `报表 / 规则引擎 / 规则命中日志` 强化为页面下半区的第一视觉主轴，继续提升信息层级、品牌辨识度和交互激活感，同时不破坏现有业务逻辑与 DOM 挂载点。

## Scope
- 强化 `apps/pwa/src/index.html` 中 `reports` 与 `rule-matches` 的数据中枢表达。
- 强化 `apps/pwa/src/rules.js` 动态生成的规则引擎 UI，使其并入同一条“数据指挥舱”视觉体系。
- 在 `apps/pwa/src/styles.css` 中新增与调整数据主轴相关样式。
- 通过回归测试保护结构标记和关键样式语义。

## Design
### 1. 数据主轴统一
`reports / rules / rule-matches` 继续共享 `command-shell-data` 语义，但规则引擎内部需要补齐自己的数据主轴标记，不能停留在普通卡片布局。规则集列表、当前规则列表、DSL 编辑器会变成同一套“分析台”。

### 2. 规则引擎成为视觉核心
`rules.js` 生成的内容加入更明确的壳层与层级：
- 外层增加数据主轴容器
- `rule-grid` 采用更偏中枢工作台的列宽节奏
- 编辑器卡片成为主焦点，左右两列列表成为辅助轨道
- `dsl-toolbar`、按钮区、列表区统一进入 command toolbar / list shell 语言

### 3. 交互与材质
数据主轴不只发光，而是强调“激活分析面板”的反馈：
- 顶部数据洗层
- 内轨道与扫描纹理
- 更强的工具栏组合感
- 编辑器面板比普通规则卡更亮、更像核心操作台

## Constraints
- 保留既有 `id`、表单控件与 JS 绑定
- 不改业务 API 或规则逻辑
- 继续仅通过 HTML/CSS/测试实现主要增强
