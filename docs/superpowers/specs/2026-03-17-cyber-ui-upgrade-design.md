# 外卖防盗监控系统 PWA 赛博高能风格升级设计

日期：2026-03-17

## 目标
在不破坏现有 DOM 结构与 JS 逻辑的前提下，对 PWA 前端进行全站统一的“高端、优雅、灵动、科技艺术向、偏赛博”升级。保留 `data-theme` 主题切换，增强动效与光效层次，允许新增少量装饰性 DOM 节点（不参与布局、不绑定逻辑）。

## 设计原则
- 保持现有结构、id、class 与数据属性不变，避免破坏现有交互与 JS 逻辑。
- 使用额外装饰节点与伪元素实现视觉增强，装饰层不参与布局流。
- 主题切换仍由 `data-theme` 控制，统一强化主题色谱与光效层。
- 动效为“高能赛博”，但保证可读性与信息层级清晰。

## 方案选择
采用“方案 B：高能赛博 + 主题系统强化”。

## 视觉系统设计
1. **主题色谱强化**
   - 在每个 `data-theme` 下，强调主色、次主色、能量色三层叠加。
   - 新增变量用于霓虹边框、光晕与能量轨迹。
2. **背景层次**
   - 深空渐变底 + 扫描线/网格 + 斜向能量纹。
   - 轻量粒子轨迹通过 CSS 伪元素/渐变实现。
3. **字体层次**
   - 标题增强字重与字距，强调科技艺术氛围。
   - 正文保持高可读性，数值与标签采用等宽字体。

## 结构与装饰层
1. 在 `body` 或 `.app` 内新增 1-2 个全局装饰容器（如 `cyber-veil`、`scanlines`）。
2. 在关键区块（Hero、控制台、报表、规则、运维等）加轻量装饰节点（角标/能量条/扫描线）。
3. 新增节点 `position: absolute` 或 `fixed`，`pointer-events: none`，避免干扰交互。

## 动效体系
1. 背景扫描线与能量纹理缓慢漂移。
2. 模块卡片边缘出现光线流动与脉冲点阵。
3. 交互态（hover/focus）添加光晕扩散与轻微上浮。

## 变更范围（文件）
- `apps/pwa/src/index.html`: 增加装饰性 DOM 节点（不会改变现有结构逻辑）。
- `apps/pwa/src/styles.css`: 新增主题变量、全局装饰层样式、动效与交互态。

## 不在本次范围
- JS 逻辑与接口对接变更。
- DOM 主结构重排。

## 验收标准
- 全站视觉统一升级为“高能赛博”风格。
- 主题切换保持可用且视觉一致。
- 交互可读性与可用性不下降。
- 新增装饰层不影响布局与逻辑。
