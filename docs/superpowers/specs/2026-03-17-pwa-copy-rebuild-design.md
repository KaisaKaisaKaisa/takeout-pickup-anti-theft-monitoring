# 外卖防盗监控系统 PWA 文案重建设计

## 概述
`apps/pwa/src/index.html` 当前中文文案已被错误编码写入，出现不可逆乱码。本次工作将**在不改变任何 DOM 结构、`id`、`class`、数据属性的前提下**，重建页面文案，同时修复 `apps/pwa/src/app.js` 中所有乱码提示/按钮文案，使界面可读、统一且符合产品调性。

## 目标
- 还原 `index.html` 的中文可读性与一致性（高端、优雅、灵动、科技艺术向、偏赛博）。
- 修复 `app.js` 内提示/按钮文案为正常中文。
- **不影响前端逻辑**：所有结构、`id`、`class` 与脚本依赖保持不变。
- 确保文件保持 UTF-8（无 BOM）可稳定显示。

## 非目标
- 不调整布局、样式或动画。
- 不修改前端业务逻辑、API 调用或数据结构。
- 不新增/删除模块与交互功能。

## 约束
- 仅替换文本内容与可读标签。
- 严格保留所有 DOM 层级结构与标识符。
- 使用 `apply_patch` 修改文件，避免工具引入二次编码损坏。

## 文案策略
- 统一术语：**告警、规则命中、证据留存、设备策略、平台回调、异常取餐、确认取餐**。
- 语气风格：短句强调 + 精炼解释，突出**低延迟、可追溯、可审计**。
- 结构指引：
  - 首屏强调“实时监测 + 证据闭环”。
  - 中段强调“规则引擎 + 报表洞察 + 权限分级 + 设备联动”。
  - 辅助模块强调“可视化、可配置、可追溯”。

## 实施范围
- 修改：
  - `apps/pwa/src/index.html`
  - `apps/pwa/src/app.js`

## 验证与验收
- `index.html` 与 `app.js` 中不再出现乱码字符（如 `�`）。
- 页面首屏、导航、模块标题与主要说明均为正常中文。
- 页面功能保持原有行为，无 JS 报错。

## 风险与应对
- **风险**：再次被错误编码写入导致二次乱码。
  - **应对**：仅使用 `apply_patch` 修改；避免外部编辑器自动转码。
